# Стековая машина (Постфиксная нотация)

Программа реализует стековую машину для вычисления выражений, записанных в обратной постфиксной нотации. Поддерживаются базовые арифметические операции, а также специальный оператор `~`.

---

## Возможности

- **Поддерживаемые операции:** `+`, `-`, `*`, `/`, `~`.
- **Пошаговая визуализация:** на каждом шаге вычисления программа выводит текущий токен и актуальное состояние стека.
- **Интерфейс командной строки:** выражение передается в качестве аргумента запуска в кавычках.
- **Формат итогового вывода:** `выражение = результат`.
- **Обработка ошибок:** сообщения при делении на ноль, нехватке операндов в стеке, неизвестных токенах или передаче выражения без кавычек.

---

## Принцип работы оператора `~`

Оператор `~` является бинарным: он извлекает из вершины стека два операнда — правый `y` и левый `x`.

1. **Если оба операнда не равны 0 ($x \neq 0$ и $y \neq 0$):**
   - Вычисляется модуль разности: `|x - y|`.
   - Результат помещается обратно на вершину стека (остальные элементы стека не затрагиваются).

2. **Если хотя бы один из операндов равен 0 ($x = 0$ или $y = 0$):**
   - Вычисляется сумма всех элементов в стеке, включая извлеченные операнды `x` и `y`.
   - Полученная сумма возводится в квадрат.
   - Обратно в стек кладется результат вычисления.

## Требования

- Python 3.10+
- Зависимости из файла `requirements.txt`

---

## Запуск

Перейдите в директорию `postfix_notation`:

```bash
cd postfix_notation
```
Создайте виртуальное окружение:

```bash
python3 -m venv .venv
```
Активируйте виртуальное окружение:

- Linux / macOS / WSL:

```bash
source .venv/bin/activate
```

- Windows (PowerShell):

```bash
.venv\Scripts\Activate.ps1
```

Установите необходимые зависимости:

```bash
pip install -r requirements.txt
```

### Запуск программы
Выражение передается строго в кавычках как один аргумент командной строки:

```bash
python3 main.py "3 0 4 ~ 2 ~"
```

Пример вывода в консоли:

```text
Токен: 3   | Стек: [3]
Токен: 0   | Стек: [3, 0]
Токен: 4   | Стек: [3, 0, 4]
Токен: ~   | Стек: [49]
Токен: 2   | Стек: [49, 2]
Токен: ~   | Стек: [47]
3 0 4 ~ 2 ~ = 47
```

Еще один пример:

```bash
python3 main.py "2 2 + 4 - 4 ~ 2 3 * +"
```
