# Лексический анализатор (Токенизатор)

Программа выполняет лексический анализ исходного кода, преобразуя входной текст в последовательность токенов согласно заданной грамматике языка.

---

## Возможности

- **Распознаваемые категории токенов:**
  - `IDENT` — идентификаторы (последовательность латинских букв, цифр и `_`, не начинающаяся с цифры).
  - `KEYWORD` — ключевые слова: `if`, `else`, `while`, `return`, `for`, `def`.
  - `INT` — целые числовые литералы (например, `0`, `42`).
  - `FLOAT` — вещественные числовые литералы с плавающей точкой (например, `3.14`, `0.001`).
  - `STRING` — строковые литералы в двойных кавычках с поддержкой экранирования (например, `"hello"`, `"a \"quote\""`).
  - `OP` — операторы: `+`, `-`, `*`, `/`, `=`, `<`, `>`, `==`, `<=`, `>=`.
  - `SEP` — разделители: `(`, `)`, `{`, `}`, `,`, `;`.
- **Игнорирование мусора:** пробелы, символы табуляции и комментарии (от символа `#` до конца строки) автоматически пропускаются.
- **Точное позиционирование:** для каждого токена фиксируются номер строки и номер столбца его начального символа.
- **Диагностика ошибок:** при обнаружении недопустимого символа или незакрытой строки программа выводит ошибку категории `lexical` с точной позицией и завершается с ненулевым кодом возврата (код `1`).

---

## Формат вывода

Каждый токен выводится на отдельной строке в формате:
```text
(<тип>, <значение>, <строка>:<столбец>)
```
## Требования

- Python 3.10+
- Зависимости из файла requirements.txt

## Установка и запуск

1. Перейдите в директорию `tokenizer`:

```bash
cd tokenizer
```

2. Создание и активация виртуального окружения

- Linux / macOS / WSL:

```bash
python3 -m venv venv
source venv/bin/activate
```

- Windows (PowerShell):

```bash
python -m venv venv
.\venv\Scripts\Activate.ps1
```

3. Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск программы

Программа принимает путь к файлу с исходным кодом через аргументы командной строки:

```bash
python3 main.py <путь_к_файлу>
```

### Пример 

1. Создадим файл input.txt:

```text
x = y * 2 + z * 3
```

2. Запуск:

```bash
python3 main.py input.txt
```

3. Вывод:

```text
(IDENT, x, 1:1)
(OP, =, 1:3)
(IDENT, y, 1:5)
(OP, *, 1:7)
(INT, 2, 1:9)
(OP, +, 1:11)
(IDENT, z, 1:13)
(OP, *, 1:15)
(INT, 3, 1:17)
```
